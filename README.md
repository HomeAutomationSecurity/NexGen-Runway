# NexGen Runway Australia

Recovered React/Vite website for NexGen Runway Australia.

## Requirements

- Node.js 20.19+ (or 22.12+)
- npm

## Commands

```sh
npm install
npm run dev
npm run build
npm run lint
npm run preview
```

React Router provides `/`, `/next-runway`, `/gallery`, `/brands`, `/parents`, `/contact`, and `/apply`. The Apply page embeds the existing Jotform application; the Contact form opens a prefilled email draft.

Local event photos, logo, and archive video are stored in `public/`. Anton and Space Grotesk fonts plus Tabler icon webfonts are bundled locally. A small set of stock photo URLs and the Jotform embed require network access.
